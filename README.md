# Greetings-Invitation-Card-Application-Development

> **Contributors start here:** Read
> [`Development_standards.md`](./Development_standards.md)
> before writing code. It defines formatting (80 cols),
> architecture, branching (`main` trunk), and PRD gates.

Premium, reliable invitation & greeting card app for India
and diaspora — True WYSIWYG, offline-first. This application
will give the better reliability to the people who are
looking for the offline editing.

## Getting Started

```sh
flutter pub get
dart format --line-length 80 .
flutter analyze
flutter test
```

See [`Development_standards.md`](./Development_standards.md)
§Appendix B for the full command reference.
